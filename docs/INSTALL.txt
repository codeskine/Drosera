Drosera, a feedback drone synth

INSTALL

1. Move Drosera.vst3 to this folder in your home folder:

     Library/Audio/Plug-Ins/VST3/

   Library is hidden in Finder. Use Go > Go to Folder and type ~/Library/Audio/Plug-Ins/VST3/

2. If your host reports the plugin as blocked or damaged, run this once in Terminal. Releases are not yet
   notarized by Apple, so macOS blocks files downloaded with a browser.

     xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/Drosera.vst3

3. Rescan plugins in your host. Drosera loads as an instrument.

Requires macOS 11 or newer.
